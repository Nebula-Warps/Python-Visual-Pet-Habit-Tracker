# Virtual Pet Habit Tracker

A Python application that gamifies habit building. Instead of just checking off a boring list, users are tasked with keeping a virtual pet alive and helping it evolve. Completing daily habits grants EXP and keeps the pet healthy; neglecting them causes the pet to take damage.

*Note: This project is currently in active development. The current version is a fully functional Terminal User Interface (TUI). A graphical frontend is planned for a future update.*

## Current Features
*   **Habit Check-ins:** Users can log daily tasks to earn EXP for their pet.
*   **Evolution System:** The pet evolves through multiple life stages (Egg, Baby, etc.) based on accumulated EXP.
*   **State Management:** The pet has dynamic stats (Health, EXP, Status).
*   **Data Persistence:** *(If you used file I/O or JSON to save progress, mention it here!)*
*   **Interactive Care System:** Users can play with and feed their pet to increase it's happiness stat.

## Tech Stack
*   **Language:** Python 3
*   **Concepts:** Object-Oriented Programming (OOP), state machines, game loops, error handling.
